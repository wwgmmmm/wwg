# Waylon Portfolio

Static portfolio website for Waylon, focused on automotive branding, campaign visuals and brand experiences.

## Preview

Open `index.html` directly in a browser. The site has no build step and no required JavaScript packages.

## GitHub Pages

1. Upload all files and the `assets` folder to the repository root.
2. Open repository Settings, then Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select `main` and `/(root)`, then save.
5. The site will be available at `https://wwgmmmm.github.io/wwg/` after deployment completes.

## Work image structure

All current project images are organized under `assets/works/`. Each project has a `cover.jpg`, while projects with additional images use `detail-01.jpg`, `detail-02.jpg` and so on.

Recommended cover ratio: 21:9 or 16:9. Recommended export: JPG, sRGB, 2400 to 3200 px wide, usually below 1.5 MB per image.
